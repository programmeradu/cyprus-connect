- Test: `docs/research/INNOVATION_CRITERIA_DMRID_RIF_56_LAYER_2026.md`. Key rule: integration is NOT innovation. Every research claim must pass the 5 Frascati criteria (novel, creative, uncertain, systematic, reproducible).
- Pathway: `docs/research/INNOVATION_PATHWAY_SLUSH_2026.md`. Flagship thesis: uncertainty-native carbon accounting (every figure has a confidence band + evidence trail; system asks for the next document that cuts uncertainty most).
- Deadline: Slush 2026 (Helsinki, November). Build aggressively toward a working, measured demo.
- Every new feature must state which research question (RQ) it serves, or it is engineering, not R&D. Log R&D time/cost separately (10% rule).
