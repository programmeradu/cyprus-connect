# Pre-registration: I-14 (sensitivity-bounded coverage backtest under self-selected realisation)

Status: LOCKED. Do not edit. Any change needs a new file (I-14-v2.md) and a new registry row.
Date: 2026-09-24. Author: founder + AI. Written before any I-14 experiment code exists.
Source: research/reports/S2_I14_PRIOR_ART.md section 6 (draft H14-1..3), thresholds unchanged.

## Setting
An estimator issues a nominal 90% interval for each of N firms. Later, only some firms report a "true" value. Reporting depends on whether the truth falls inside the interval (MNAR). Target: true coverage c over all N firms. Pass line for "honest": c >= 0.85.

## Test (candidate, T-bound)
- Let k of n reporters fall inside their interval. Take the 95% Clopper-Pearson interval [p_lo, p_hi] for reporter coverage.
- Sensitivity model: the odds of reporting for a covered firm vs an uncovered firm lie in [1/G, G]. Then the odds of c lie in [odds(p_lo)/G, odds(p_hi)*G].
- Verdict: GREEN if the lower end of the c-set >= 0.85; RED if the upper end < 0.85; AMBER otherwise.
- G fixed at 2.0 for the pass/fail hypotheses. G in {1.0, 1.5, 3.0} reported as secondary.

## Baseline (T-naive)
Same verdict rule with G = 1 (no selection correction): exception count on reporters only, like Basel traffic light.

## Data generation
N = 1,000 firms per run, 2,000 runs per cell, seed 20260924. Reporting probability 0.15 base; the covered/uncovered reporting odds ratio is the true selection G_true. n realised reporters targeted at 150 by scaling.

## Hypotheses (fixed)
- H14-1 (size): c_true = 0.90, G_true drawn uniformly in [1/2, 2]. False-RED rate of T-bound <= 5%. FAIL if above.
- H14-2 (power): n = 150, c_true = 0.75, G_true drawn uniformly in [1/2, 2]. T-bound says RED in >= 80% of runs. FAIL if below.
- H14-3 (correction matters): c_true = 0.75, G_true = 2 (uncovered firms report half as often). T-naive gives GREEN in >= 30% of runs. FAIL if below.

## Secondary (reported, not pass/fail)
- Minimum n for H14-2 power >= 80% at G = 1.5 and 2.0.
- Noisy truth: 10% of realised values misclassified (in/out flipped).
- Power curve over c_true in {0.60, 0.65, 0.70, 0.75, 0.80}.

## Kill rules
- If H14-2 fails at G = 2 and minimum n for 80% power exceeds 1,000 reporters, I-14 is reported as dead on power grounds at SME scale.
- All results are synthetic. No threshold changes after this date.
