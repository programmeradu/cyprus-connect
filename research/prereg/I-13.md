# Pre-registration: I-13 (hierarchical fusion of sector proxy prior with sparse SME documents)

Status: LOCKED. Do not edit. Any change needs a new file (I-13-v2.md) and a new registry row.
Date: 2026-09-24. Author: founder + AI. Written before any I-13 experiment code exists.
Source of hypotheses: research/reports/S2_I13_PRIOR_ART.md (draft H13-1..3), wording set by the founder directive of 2026-09-24.

## Target quantity
Annual Scope 1 + Scope 2 (location-based) emissions of one micro/small firm, tCO2e.

## Models
- Candidate (C): hierarchical Bayesian model. Firm log-intensity (tCO2e per EUR turnover) ~ Normal(mu_sector, sigma_sector). mu_sector ~ Normal(log EXIOBASE proxy_sector, tau). Partial pooling across Cyprus NACE groups. Document likelihood: each bill observes one billing period of one source (electricity or fuel), lognormal seasonal and reading noise. Fitted with NumPyro NUTS (PyMC used for the SBC check).
- Baseline 1 (B1, hard switch): PCAF-style fallback used by vendors. Per source: if the firm has >= 1 document for that source, annualise the documents (mean per period x periods per year); else use the EXIOBASE proxy x turnover x sector source share. Proxy-only firms get proxy x turnover. B1 has no interval of its own; for H13-1 its interval is the proxy x a lognormal spread with the pedigree-style GSD 2.0 (report only).
- Baseline 2 (B2, conformal): MAPIE split-conformal regressor on log emissions. Features: sector, log turnover, number of documents per source, log annualised document value per source (0 + missing flag if none). Trained on a separate labelled set of firms of equal size. B2 needs labelled truth; C does not. This difference is reported.

## Hypotheses and fixed thresholds (nominal level 90%)
- H13-1 (prior calibration): for firms with 0 documents, inside a portfolio where 50% of firms have documents, C's 90% intervals cover the true value in [0.85, 0.95] of firms. FAIL if outside.
- H13-2 (shrinkage): for the same firms, going from 0 to 3 documents shrinks C's median relative half-width ((hi - lo) / 2 / median) by >= 50%, and coverage at 3 documents stays in [0.85, 0.95]. FAIL if either condition fails. Results at 1 and 2 documents are reported.
- H13-3 (point accuracy): on firms with 1-3 documents, the median absolute relative error of C's posterior median is >= 20% lower than B1's. FAIL if < 20% lower.

## Secondary (reported, not pass/fail)
- Ablation A1: tau fixed near 0 (trust the proxy, no pooling). Ablation A2: no pooling across sectors (independent mu_sector with a wide prior).
- B2 coverage and width at the same document counts.
- Stress: 0%, 25%, 50% of documents missing; OCR noise on 5% of documents (x10 digit error or +/-3%).
- Misspecification scenario: firm heterogeneity Student-t (df = 3) instead of normal, and proxy bias sd 0.5 instead of 0.3.
- SBC (simuk) on a reduced PyMC version of C: rank histograms must not reject uniformity (chi-square p > 0.01) for mu, tau, sigma.

## Data rules
- Ground truth is synthetic. All results are reported as "synthetic only". No evaluator claim until real firms with known emissions (bank partner or 3-5 pilot SMEs) exist.
- Proxy priors: EXIOBASE 3.9.6 (Zenodo 10.5281/zenodo.15689391), year 2022, industry-by-industry, Cyprus rows. Scope 1 = direct GHG (GWP100) per EUR output; Scope 2 = Cyprus electricity purchases per EUR output x Cyprus electricity sector intensity.
- Generator validation: synthetic turnover per firm must pass KS p > 0.05 or normalised Wasserstein <= 0.1 against Eurostat SBS Cyprus micro-firm marginals. If only means are available, this is a calibration target, not validation, and the generator is reported as NOT validated.
- Seed 20260924. N = 1,000 firms per scenario.

## Kill rules
- Any H FAIL is reported as FAIL. No threshold change after this date.
- If C does not beat A1 on coverage or error, the pooling layer is not the source of value and is reported as such.
