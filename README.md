## 🌱 Overview

VerdeIQ is a comprehensive AI-powered sustainability platform designed specifically for Small and Medium Enterprises (SMEs). We empower businesses to track, optimize, and report their environmental impact with cutting-edge technology and actionable insights.

### Key Features

- **🤖 AI-Powered Analytics** - Advanced machine learning to uncover sustainability opportunities
- **📊 Real-Time Monitoring** - Track carbon footprint, energy consumption, and waste metrics
- **📝 Automated Reporting** - Generate compliance-ready sustainability reports (CSRD, ESRS, VSME)
- **💰 Energy Cost Savings** - Calculate real savings from efficiency improvements
- **🏆 Industry Benchmarking** - Compare emissions against industry peers
- **✅ Compliance Checker** - Automated requirement tracking for regulatory changes
- **🎓 AI Learning Platform** - Personalized sustainability courses generated by AI
- **🎬 Media Studio** - Generate sustainability-focused images and videos
- **🔗 Integrations** - Connect with QuickBooks, Xero, and more

## 🚀 Quick Start

### Prerequisites

- Node.js 18+ or Bun
- A Gemini API key (for AI features)
- Optional: Clerk account (for Google OAuth)

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/yourusername/verdeiq.git
cd verdeiq
```

2. **Install dependencies**
```bash
npm install
# or
bun install
```

3. **Set up environment variables**
```bash
cp .env.example .env
```

Edit `.env` and add your API keys:
- `GEMINI_API_KEY` - Required for AI features
- `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` & `CLERK_SECRET_KEY` - For authentication
- Other optional keys (see `.env.example` for details)

4. **Set up the database**
```bash
npm run db:push
# or
bun run db:push
```

5. **Run the development server**
```bash
npm run dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to see VerdeIQ in action! 🎉

## 📚 Documentation

### Key API Endpoints

#### Authentication
- `POST /api/auth/sign-in` - Email/password login
- `POST /api/auth/sign-up` - User registration
- `POST /api/auth/sign-out` - Logout

#### Dashboard
- `GET /api/dashboard/metrics` - Current sustainability metrics
- `GET /api/dashboard/historical` - Historical data
- `GET /api/dashboard/suggestions` - AI-generated suggestions

#### Emissions
- `POST /api/emissions` - Log emissions entry
- `GET /api/emissions-history` - Fetch emissions history
- `POST /api/emissions/estimate` - Estimate emissions from activity

#### Learning Platform
- `GET /api/learn/courses` - List available courses
- `POST /api/learn/generate-course` - Generate AI course
- `POST /api/learn/lessons/[id]/complete` - Mark lesson complete
- `GET /api/learn/certificates/[courseId]` - Download certificate

#### Media Studio
- `POST /api/generate-image` - Generate AI image
- `POST /api/generate-video` - Generate AI video
- `GET /api/studio/generations` - List generation history
